# The CEO Bond

**Ideas. Influence. Impact.**

The official website for **The CEO Bond**, an independent digital magazine exploring leadership, enterprise, innovation, culture, and the people shaping tomorrow.

## Pages

- `index.html` — Main magazine landing page
- `magazine/index.html` — Editorial journal and article categories

## Run locally

This is a static HTML/CSS website. Open `index.html` in a browser, or serve the repository with any static web server.

## Deployment

The repository can be deployed directly to GitHub Pages, Cloudflare Pages, or another static hosting provider. No build step is required.
